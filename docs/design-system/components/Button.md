Buttons come in three weights: primary (accent fill), secondary (raised fill with control border) and quiet (control border only).

- **Primary:** one per screen. This is Start, plus Convert inside a nudge. It uses `accent` with `on-accent` text, at 48px tall in the panel and 30px when inline.
- **Secondary:** Add files. It uses `bg-raised`, a `control-border` outline and `text`.
- **Quiet:** Clear list and Show in folder. It has a `control-border` outline on a transparent fill, with `text-muted` text, or `text` for Show in folder.
- **Focus:** every button shows a 2px `accent` focus ring offset by 2px.
- **Disabled:** the button sits at 40% opacity and its cursor changes to not-allowed. For example, Start is disabled with an empty list.
