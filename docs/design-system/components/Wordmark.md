The wordmark is the lowercase "smartpress" set beside the chevron mark, and it sits top-left of the header.

- **Mark:** a 28px rounded square with two inward chevrons, drawn as a 2px `accent` stroke (`docs/design-system/smartpress-mark.svg`).
- **Type:** "smart" is Geist 400 in `text-muted`, and "press" is Geist 700 in `text`, both at 20px with `-0.03em` tracking.
- **Spacing:** keep 12px between the mark and the word.
- **Version tag:** the optional tag is `label` mono in `text-muted`, with a `line` outline and `radius-sm` corners.
- **Don'ts:** never recolour "press", and never set the word in capitals.
